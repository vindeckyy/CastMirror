Linux · C++20 · Cast Streaming

Native Chromecast display mirroring. Low latency. No Chrome.

CastMirror is a GTK sender that discovers Cast devices on your LAN, captures the desktop and system audio, and streams H.264 + Opus over the same Cast RTP/RTCP path Chrome uses for “Cast screen”.

Product

One-click Cast. Honest latency.

Target playout delay is about 200 ms — Chrome-class mirroring, not game streaming. Host speakers mute while audio is on the TV, then restore on Stop.

Discover and Cast

mDNS for nearby Chromecast / Google TV / Cast TVs, or add a device by IP. GTK UI plus a CLI.

Quality you can see

Auto, High, Balanced, Smooth. Per-profile bitrate slider (1–25 Mbps), locked while the session is live.

Host audio stays off the PC

Capture is the default sink monitor. The sink is muted for the session so you do not hear the stream twice.

Adaptive on RTCP

CAST checkpoints, NACK / CST2, and PLI drive bitrate and keyframes. Hard Stop under 500 ms.

Protocol crypto

TLS on port 8009. Media uses Cast Streaming AES-128-CTR with per-frame IVs — as Chrome mirroring does.

Not a Chrome wrapper

No embedded browser. Not HLS fling. Windows WinUI in-tree is a blueprint, not the shipping Linux UI.

Pipeline

Capture to Cast UDP

Compatibility

Cast video devices Chrome can mirror to

Chromecast 3rd gen, Ultra, Google TV, and built-in Cast TVs. Nest Hub is 720p-class.

Quick start

Build on Linux

sudo apt install -y build-essential cmake ninja-build pkg-config protobuf-compiler libprotobuf-dev \
    libssl-dev libopus-dev libpulse-dev libx11-dev libxext-dev libxrandr-dev libxfixes-dev \
    libxcomposite-dev libxdamage-dev \
    libva-dev libavcodec-dev libswscale-dev libavutil-dev nlohmann-json3-dev libgtest-dev \
    libgtk-4-dev libadwaita-1-dev
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build -j"$(nproc)"
./build/app/castmirror-gui
